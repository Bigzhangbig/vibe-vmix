# 纸飞机 · 50届决赛

这是参考 2025 年北理工第 50 届深秋歌会决赛重新绘制的网页包装。补丁只含新的可编辑图形，不含往届原图、字体、选手数据或原工程。

## 导播怎么用

1. 退出工作台。把补丁解压到 Windows 上「转播包装工作台.exe」的同级目录，允许覆盖同名文件，保留自己的 `data` 和素材。重启后打开 **舞台节目 → 深秋歌会**。本版只保留纸飞机决赛包装。
2. 报幕、嘉宾和选手可用「居中包装」或「靠下叠画」。两者都是 1920×1080 的透明画布，只有图形覆盖的区域会上屏，画布四边都留有透明余量。歌词在左下用唱片图标配文字；可手填，或留空跟随「节目与播出」的逐句歌词。选手阵容每行输入一位，按两行三列显示。冠亚季用「名次」，最佳人气奖单独选「人气奖」，不要混在排名里。
3. 点击「保存并上屏」才把当前包装送到净输出。右下角标可以单独开关，不用为切换歌词、报幕或排名重上角标。编排时先在预监中看位置，再进 vMix。
4. 在「vMix 连接」把净输出 URL 添加成 1920×1080 的 Web Browser 输入，再用 Overlay 1–4 进出画。工作台内的角标与内容是同一浏览器输入的两个图层；关闭 vMix 的这个 Overlay 会一起撤下。要输出备用素材，可把当前画面导出为透明 PNG 序列或带 Alpha 的 ProRes 4444 MOV（MOV 需要 FFmpeg）。
5. 不在 Windows 导播机旁时，先在 Mac 浏览器打开补丁里的「模板试映.html」。此页面只试映，不向 vMix 送出画面。

## 用自己的原主视觉

用解压工具从「冬天歌会.zip」取出「主视觉.png」，原 ZIP 不变。工作台里点「导入主视图」，选择「保持完整」以保留原图 3:2 构图，也可填满居中图板并裁切。图片只显示在居中包装的图板内部，四周仍是透明的；靠下叠画不会铺这张图。

也可在源码目录用 Python 3 只取这一张图，不用解压整个包。两个路径改为自己的文件，输出名不可已存在：

```sh
python3 scripts/extract-finale50-main.py "冬天歌会.zip" "决赛主视觉.png"
```

## 要保留原版动画时

原包的报幕、歌词和角标 AE 工程有旧电脑的外链路径。请在单独目录解包，在 AE 打开工程并重连素材，另存一份再通过工作台「素材与导入」链接工程并选择合成。工作台调用本机 AE 渲染，不会把 AE 或 GT 的图层自动搬进网页。原版 PNG 序列也可按组解包，选首帧作为 vMix Image Sequence 输入；它们是动画元素，不是带歌词或比分的完整包装。
